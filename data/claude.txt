== OVERVIEW ==
Claude is the AI assistant made by Anthropic, an American AI safety and research company founded in 2021 by former OpenAI researchers (including Dario and Daniela Amodei). Claude was first released in March 2023.
Claude is known for careful, well-written answers, strong coding and agentic abilities, long-context understanding and a focus on safety and honesty.
Consumer access: claude.ai on web, desktop and mobile apps. Free plan with limits, plus paid plans (Pro, Max, Team, Enterprise). Other products: Claude Code (agentic coding tool for developers), Claude in Chrome, Claude for M365 and more. Developers use the Claude API (Claude Platform).
Best known for: coding, long documents, writing quality, agents, safety.

== CURRENT MODELS (API) ==
Claude models come in tiers (from smallest to largest): Haiku, Sonnet, Opus, and the new top tier Fable/Mythos.
1. Claude Fable 5.1 - top-tier (Mythos-class) model, most capable, with extra safety measures. Most expensive.
2. Claude Opus 5.5 - powerful model for complex challenges, deep reasoning, advanced coding and agents.
3. Claude Sonnet 5 - balanced model: strong quality with good speed and lower cost. Popular default for production apps.
4. Claude Haiku 4.5 - smallest, fastest and cheapest Claude model; good for high-volume, low-latency tasks.
Note: Claude Mythos 5.1 (same underlying model as Fable 5.1) is available only to selected trusted organizations under Anthropic's Project Glasswing, not to the general public.

== COMPARISON OF CLAUDE'S OWN MODELS ==
- Capability: Fable 5.1 > Opus 5.5 > Sonnet 5 > Haiku 4.5.
- Price: Fable costs 2.5x Opus; Opus costs 2x Sonnet; Sonnet costs 2x Haiku.
- Speed: Haiku fastest, Fable/Opus slower.
- When to choose: Fable/Opus for the hardest reasoning and long agentic coding tasks; Sonnet for most apps; Haiku for simple, fast, cheap workloads like classification, routing, customer support.

== API BASICS ==
- Get an API key from the Claude Console (platform.claude.com), set ANTHROPIC_API_KEY.
- Official SDKs: Python (pip install anthropic), TypeScript, and others.
- Main endpoint: Messages API.
- Key API features: streaming, tool use (function calling), vision (image and PDF input), prompt caching, batch processing, extended thinking, structured outputs, citations, 1M token context.
- Python example:
  import anthropic
  client = anthropic.Anthropic()
  msg = client.messages.create(model="claude-sonnet-5", max_tokens=1024,
        messages=[{"role": "user", "content": "Explain RAG in simple words"}])
  print(msg.content[0].text)

== STRENGTHS ==
- Excellent at coding and agentic tasks (Claude Code is widely used by developers).
- 1M token context on recent models at standard price - great for long documents and big codebases.
- High-quality, natural writing; follows complex instructions well.
- Strong safety focus.

== WEAKNESSES / LIMITATIONS ==
- No native image generation.
- Top models (Fable, Opus) are costly for high-volume use.
- Closed-source; cannot self-host.
- Free consumer plan has usage limits.

== BEST FOR ==
Coding assistants and developer tools, analysis of long documents (contracts, research papers, codebases), AI agents, professional writing.
